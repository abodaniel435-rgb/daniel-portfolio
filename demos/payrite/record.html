On this page

    00 · Why this page exists

    A payroll is a list of promises

    Every row is a number you told somebody you would pay, and a number you told the state you would remit. Keeping the list is what lets you say so again in March.

    It is not a backup

    localStorage lives in one browser on one device. Clear site data and it is gone. Export the CSV every month.

    It is a working document

    Add the real packages, remove leavers before the run, and the totals on this page become the figures you file.

    It is your own evidence

    If a board queries an employee's PAYE, the saved row plus the payslip is the answer.

    02 · Turning the record into a decision

    What to do with these numbers

    A record is only useful if something changes because of it. This is the cadence the entries support.

    Weekly

    New starter in, row added

    Add the package the day the contract is signed, not the day the first salary is due. The roster is then a hiring plan you can price.

    Pay day

    Reconcile the bank instruction

    The net column total should equal exactly what you are about to send. If it does not, one row changed and you have not been told.

    By the 10th

    The PAYE column is the return

    Export the CSV, hand it to whoever files, and keep the acknowledgement next to it.

    Quarterly

    Compare the employer cost line

    Three months of the cost column tells you whether the package structure drifted — a raise here, a new benefit there.

    Annually

    Rebuild, do not edit

    Twelve months of rows is not an archive. Export the CSV, start a fresh roster for the new year, keep the file.
