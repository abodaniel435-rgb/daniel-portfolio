    00 · Why keep this log

    A landed cost is a promise you make to yourself about the future

    Each row is a set of assumptions about a rate, a band, a dwell and a truck. Writing them down is the only way to find out later which of them you got wrong.

    It is not a backup

    localStorage lives in one browser on one device. Clear site data and the files are gone, and the sixty-file cap means old ones fall off the end anyway. Export the CSV.

    The full file stays with the tool

    Each saved shipment carries every field you typed, which is why the calculator's Load button can refill the whole form. This page shows the results only, and the CSV here exports the columns above.

    It is your evidence at the window

    An assessment that disagrees with your estimate is easier to argue line by line when you have the trail, the printed sheet and the previous three files beside it.

    02 · Turning the record into a decision

    What to do with these numbers

    A record is only useful if something changes because of it. This is the cadence the entries support.

    Before ordering

    Compare two saved files, not one

    Same goods, two freight structures, two dwell assumptions. The landed column decides the argument faster than a forwarder's opinion does.

    At assessment

    Put the real numbers beside the estimate

    Save again with the actual rate, the actual duty line and the actual days. The gap between the two rows is the number you should be managing.

    Monthly

    Watch the blended cost per unit

    If it drifts up while the bands did not move, the answer is in the freight structure, the dwell or the rate, and the log tells you which.

    When the naira moves

    Sort by the last column

    That is the rate at which each file's margin disappears. Do not average it across currencies: a USD file and a CNY file have nothing in common except the column.

    Before the second container

    Kill the bottom row

    Sort by net ROI and remove the worst file from the plan. Reordering the same goods is not loyalty, it is working capital.

    Quarterly

    Export, then start again

    Sixty files is a working list, not an archive. Download the CSV, keep it with the invoices, and let the next quarter have a clean sheet.
