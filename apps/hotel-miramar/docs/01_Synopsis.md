# Project Synopsis — Hotel Miramar SG Room Booking System

**Title:** Hotel Room Booking System for Hotel Miramar SG  
**Type:** Aptech eProject  
**Technology:** Python (Flask), SQLAlchemy, MySQL/SQLite, HTML5, CSS3, JavaScript  

## Purpose
Provide an online platform for guests to view hotel information, search and book rooms, and for administrators to manage rooms, bookings, customers, feedback, and homepage content.

## Scope
- Public website (home, about, rooms, attractions, location, contact)
- Customer registration, authentication, booking lifecycle
- Administrator dashboard with full management capabilities
- Secure authentication, availability validation, booking status workflow

## Key Modules
1. Public Website  
2. Registered Customer Portal  
3. Administrator Dashboard  

## Outcome
A complete, responsive, premium-styled web application demonstrating full-stack development skills required by the Aptech eProject specification.
