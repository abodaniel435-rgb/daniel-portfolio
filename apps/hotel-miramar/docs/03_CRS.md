# Customer Requirement Specification

## Functional Requirements
| ID | Requirement | Priority |
|----|-------------|----------|
| FR1 | Guest can view hotel info, rooms, attractions, location | High |
| FR2 | Guest can submit contact enquiries | High |
| FR3 | User can register, login, recover password | High |
| FR4 | User can search, view, book rooms | High |
| FR5 | User can view and cancel own bookings | High |
| FR6 | User can update profile | Medium |
| FR7 | Admin can CRUD rooms | High |
| FR8 | Admin can manage customers | High |
| FR9 | Admin can approve/disapprove bookings | High |
| FR10 | Admin can manage feedback and slider | Medium |
| FR11 | System prevents conflicting approved bookings | High |

## Non-Functional
- Responsive design (desktop, tablet, mobile)
- Secure password storage (hashed)
- CSRF protection on forms
- Premium visual design with background imagery
