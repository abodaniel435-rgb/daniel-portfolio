4. Features in scope

  • Account authentication — Register, sign in, password hashing, throttled logins and a private portal.
  • Admin dashboard — Operations console with live counts, status controls and an audit trail.
  • Bookings & tracking — A public request form with a reference, an email outbox entry and a public status lookup.
  • Contact inbox — A validated enquiry form that persists to the database and an admin inbox.
  • Reports — Live aggregates over real rows: volume, status mix, revenue and demand.

6. Roles

  • Administrator — Full access to every record, person, payment, inbox, report and automation run. (seeded)
  • Shipper — Own portal, own records and own orders only.
  • Public visitor — Home, request form, catalogue and reference lookup. No access to other people’s data. (seeded)

7. Automation

  • Upcoming reminders (Every 15 minutes) — Emails a reminder for confirmed shipments due tomorrow and stamps reminder_sent_at so it never repeats.
  • Close past requests (Daily) — Closes past open shipments as “Failed”, writes a timeline event and emails the customer.
  • Daily operations digest (Daily) — One summary email to the active administrator: volume, pending work, new enquiries and delivery failures.
